각 대사에 ① 합성음성 ▶과 ② 성우음성 ▶ 버튼을 따로 두었습니다. 합성음성은 브라우저의 중국어 읽어주기로 재생됩니다. 성우음성은 정확한 원본 오디오와 대사 구간이 연결된 경우에만 해당 한 줄이 재생됩니다. 문장별 성우 음원 파일과 정확한 구간 정보는 아직 미완성이지만, 성우 ▶ 버튼을 누르면 해당 장면의 실제 중국어 더빙 녹화가 웹페이지 안에서 열립니다. 문장 구간이 확인된 녹음은 저장 위치에서 재생하고, 나머지는 원본 장면 전체를 재생합니다.

음성 가공 스튜디오

다운로드 가능한 원본 녹음이나 본인 게임 녹화 파일을 선택하면 브라우저 안에서 듣고 구간을 잘라 별도의 음성 트랙으로 내보냅니다. 영상 화면은 표시하지 않습니다. 클립 출력을 위해 MP3·WAV·OGG를 권장합니다. MP4는 재생 가능 환경에서도 브라우저의 음성 추출이 제한될 수 있습니다.

현재 오디오 트랙 미연결

처음부터 끝까지 녹음 파일을 보관하는 방법

음성 가공은 선택한 원본 파일을 사용자 브라우저 안에서만 처리합니다. 원본 녹음을 외부 서버에 전송하지 않습니다. 개별 대사에 적용하려면 위의 '음성 연결'에서 해당 파일을 선택하고 시작·종료 초를 입력합니다.

대사집 전체 불러오기

보유한 원문을 TSV 파일로 불러오면 대사 수에 관계없이 이 형식으로 펼쳐집니다. 탭 구분: 장면 / 화자 / 한국어 / 중국어 / 병음 / 영상URL. 중국어는 그대로 보존합니다.

원음 파일을 연결한 뒤 직접 듣기

대사 옆의 + 음성 연결 → 갖고 있는 정식 게임 녹음 파일(MP3·OGG·WAV 등) 선택 → 저장. 길게 녹음된 한 장면은 장면 전체 녹음 연결을 이용한 뒤 대사별 시작·끝 시간을 설정할 수 있습니다. 연결된 원음은 이 브라우저 안의 저장소에 보관됩니다(지원되지 않는 환경에서는 현재 열람 중에만 유지).

현재 확인된 공개 음성 모음 영상은 원저작권 및 업로더의 재배포 조건 때문에 자동 추출·내장하지 않았습니다. 오디오 파일을 보유한 경우에는 음성 트랙을 직접 가공해 독립적으로 재생할 수 있습니다.

녹음 파일 연결

한 장면 전체 녹음은 대사별 시점을 지정할 수 있습니다. 아래 시작·끝 시간을 비워 두면 녹음 전체가 재생됩니다. 정확한 특정 대사만 듣고 싶으면 시간을 지정하세요.

선택한 음성 파일은 외부 서버로 업로드하지 않으며, 이 브라우저 내에서 재생합니다.
